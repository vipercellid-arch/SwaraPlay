# SwaraPlay v3.0.0 — OLED Cinema (Mobile/Tablet & Android TV)

Aplikasi nonton Android OLED hitam pekat (`#0A0A0C`) bergaya **Swara** untuk **HP, Tablet, dan Android TV / Google TV** — 100% gratis tanpa langganan/VIP, tanpa login, dan tanpa perlu TMDB API key.

## Varian APK
- **`SwaraPlay-v3.0.0.apk`** (`com.swara.play`) — Untuk HP & Tablet (Floating Bottom Pill di HP, Navigation Rail di Tablet).
- **`SwaraPlay-TV-v3.0.0.apk`** (`com.swara.play.tv`) — Khusus Android TV / Google TV dengan antarmuka 10-foot, navigasi D-Pad remote penuh, `focusRestorer()`, dan overscan aman.

## Aturan Rilis GitHub
- Semua rilis otomatis dari tag `v*` diterbitkan sebagai **Pre-release (`--prerelease`)** terlebih dahulu untuk pengecekan sebelum dipromosikan menjadi rilis final.
- Aplikasi otomatis memantau GitHub Releases (`vipercellid-arch/SwaraPlay`) dan menampilkan **Notifikasi Android + Banner Pembaruan** ketika versi lebih baru tersedia.
