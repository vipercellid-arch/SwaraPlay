# SwaraPlay v2.0.0 — OLED Cinema Android

Aplikasi nonton Android OLED hitam pekat bergaya **Swara** (`#0A0A0C` + `#E11D48`) untuk **Film, Series, Drama Asia, dan Anime** — 100% gratis, tanpa login, dan tanpa perlu TMDB API key.

## Pembaruan Utama v2.0.0
- **UI Ala Swara:** Floating glassmorphic bottom bar pill, Hero Showcase Carousel, Profil & Setelan dengan maskot monokrom, serta **Mode Performa** (`Otomatis / Anti-Panas / Maksimal`).
- **Player Matang + True Fullscreen Landscape:** Mendukung `WebChromeClient.onShowCustomView` layar penuh horizontal (immersive mode), **8+ server streaming aktif** (VidSrc.cc, VidLink.pro, Embed.su, VidSrc.xyz, AutoEmbed, MultiEmbed, SmashyStream, + Anime Sub/Dub + Stremio Addons di Media3 ExoPlayer), tombol Reload Server, dan Smart AdBlock yang aman untuk CDN video.
- **DNS-over-HTTPS (Cloudflare DoH) Bawaan:** Membantu menembus blokir DNS ISP untuk katalog & API.
- **Katalog Gratis Tanpa Login:** Cinemeta Stremio (Film, Series & filter genre), IMDb Suggestion fallback, TVMaze Drama Asia, dan AniList GraphQL (Trending, Populer & Top Rated Anime).
- **Subtitle Wyzie (`sub.wyzie.io`):** Prioritas Bahasa Indonesia & Inggris untuk ExoPlayer native + salin tautan `.srt`.
- **Donasi QRIS ViperCell Asli & Auto-Updater GitHub Releases:** Zoomable + Simpan ke Galeri, cek rilis otomatis dari `vipercellid-arch/SwaraPlay`.
